
# User Stories – Taghreed

## User Story 1: Smart Room Finder

As a student, I want to search for lecture rooms and see clear building pictures and directions so that I can find my classroom easily.

### Acceptance Criteria
1. The student can search for a room by its name or code.
2. The system displays the correct building and room information.
3. The system provides a building picture and clear directions.

## User Story 2: Lecture Change Notifications

As a student, I want to receive notifications when my lecture location or time changes so that I can attend my lecture at the correct place and time.

### Acceptance Criteria
1. The system updates the lecture location or time based on information provided by the lecturer.
2. The student receives a high-priority notification when the lecture location or time changes.
3. The updated lecture location and time are displayed in the timetable.

## User Story 3: Priority Announcements

As a student, I want to see announcements organised by importance so that I can find important university information quickly.

### Acceptance Criteria
1. Announcements are organised into High, Medium and Low priority levels by the colours.
2. High-priority announcements are clearly highlighted by a red colour.
3. The student can open an announcement to read its details.
